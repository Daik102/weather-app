<h1>Project: Weather App</h1>
A Weather app with several features.
<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Asynchronous live weather data fetching from Visual Crossing weather API

- Multiple timeframes including 2-day, 15-day, and hourly forecast mode

- Saving location with LocalStorage

- Responsive Design implemented

<h3>Tech Stack</h3>

- Frontend: HTML CSS JavaScript

- Build Tool: Webpack

- Icons: <a href="https://pictogrammers.com/">Pictogrammers</a>
